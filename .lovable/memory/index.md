# Project Memory

## Core
Light industrial theme, Dieter Rams × cassette futurism. Primary burnt orange hsl(12 76% 50%).
Background off-white hsl(0 0% 96%), surfaces white, text near-black hsl(0 0% 12%).
Space Grotesk headings, JetBrains Mono body. No gradients, no glow, no neon.
Timer is NOT interactive — live visualization of current scheduled block.
Clicking task = edit panel, NOT focus mode. Drag is primary interaction.
Priority: FLEX(0) → SEMI(1) → FIXED(2) → LOCK(3). Moving escalates +1.
SEMI can only move within week. FIXED only within day. LOCK = blocked modal.
Accent used ONLY for: now line, active task, LOCK state, interaction feedback.
